KASETTI — Project Overview

Purpose

KASETTI aims to make it easier for patients to verify the professional registration and identity of a doctor through a simple digital experience.

Core Concept

A doctor can be associated with a KASETTI QR code. When a patient scans the QR code, the system can provide access to relevant professional information obtained from trusted medical-registration sources.

Key Principles

- Patient-friendly
- Simple verification
- Trusted information
- Privacy-conscious
- Easy to access
- Scalable

Current Stage

KASETTI is currently in the early concept and validation stage.

Next Objectives

1. Validate the concept with relevant stakeholders.
2. Understand available official medical-registration data sources.
3. Define the minimum viable product (MVP).
4. Develop a prototype.
5. Test the user experience.
6. Explore partnerships and implementation opportunities.
