KASETTI — MVP Workflow

Objective

Create a simple patient-facing workflow for verifying a doctor's professional identity using a KASETTI QR code.

Primary User Journey

1. Doctor Registration

An authorized doctor is registered in the KASETTI system.

2. Verification

The doctor's registration information is checked against an appropriate trusted/authoritative source, subject to technical access and applicable regulations.

3. QR Code Creation

A unique KASETTI QR code is generated for the verified doctor.

4. QR Code Placement

The QR code may be displayed at an approved location such as:

- Clinic
- Hospital
- Consultation room
- Doctor identification material

5. Patient Scans QR Code

The patient scans the QR code using a smartphone camera.

6. Verification Page

The patient is taken to a KASETTI verification page.

The page should clearly indicate the verification status and display relevant professional information.

7. Patient Decision

The patient can review the information and determine whether the displayed professional information matches the doctor they intend to consult.

Simplified Flow

Doctor
↓
Registration Verification
↓
KASETTI QR Code
↓
Patient Scans
↓
KASETTI Verification Page
↓
Trusted Professional Information
↓
Patient Makes an Informed Decision

MVP Priority

The first prototype should focus only on:

QR Scan → Verification Page → Doctor Information → Verification Status

Additional features should be considered after the core workflow is validated.

Important Considerations

The final implementation must consider:

- Medical-registration authority requirements
- Data accuracy
- Privacy
- Security
- Consent
- QR-code misuse
- Expired or cancelled registrations
- False or duplicate profiles
- Accessibility
