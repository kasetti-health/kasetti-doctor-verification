# KASETTI Prototype Flow

## Patient Journey

1. Patient sees the KASETTI QR code.
2. Patient scans the QR code using a mobile phone.
3. KASETTI opens the doctor's verification page.
4. Doctor's details are displayed.
5. KASETTI checks the registration information against an authoritative medical registry.
6. Patient sees the verification result.

## Basic Verification Result

### VERIFIED
- Doctor name
- Qualification
- Registration number
- Registration authority
- Registration status
- Verification date
